# Mini Proyecto: Tic Tac Toe

## Descripción del proyecto

Este proyecto consiste en el desarrollo de un juego de Tic Tac Toe (Tres en Raya) utilizando el lenguaje de programación C++. El programa permite jugar contra otro jugador o contra la CPU, mediante un tablero de 3 × 3.

El propósito es aplicar los conocimientos adquiridos en programación, utilizando funciones, estructuras de control, variables y arreglos para desarrollar un juego interactivo desde la consola.

## Funcionalidades

- Jugar contra otro jugador.
- Jugar contra la CPU.
- Consultar las instrucciones del juego.
- Registrador las victorias de los jugadores y los empates.
- Mostrar el tablero durante las fiestas.

## Tecnologías utilizadas

- Lenguaje: C++.
- Compilador: GCC (G++).
- Depurador: GDB.
- Entorno de desarrollo: Visual Studio Code.

## Cómo ejecutar el programa

1. Descargar o clonar este repositorio.
2. Abrir la alfombra del proyecto en Visual Studio Code.
3. Abrir el archivo `Mini_Proyecto_Tic_Tac_Toe.cpp`.
4. Compilar y ejecutar utilizando la configuración de depuración de VS Code o G++.
